# Lean 快速开始指南

> 5分钟上手量化交易开发

---

## 🚀 快速启动

### 1. 运行你的第一个策略

```powershell
# 确保已经构建项目
dotnet build

# 进入 Launcher 目录
cd Launcher/bin/Debug

# 运行默认策略
dotnet QuantConnect.Lean.Launcher.dll
```

默认会运行 `BasicTemplateFrameworkAlgorithm`，回测时间：2013-10-07 至 2013-10-11

### 2. 修改运行的策略

编辑 `Launcher/bin/Debug/config.json`：

```json
{
  "algorithm-type-name": "BasicTemplateAlgorithm",  // 改成你想运行的算法
  "algorithm-language": "CSharp"
}
```

### 3. 创建你的第一个策略

在 `Algorithm.CSharp` 目录创建 `MyFirstStrategy.cs`：

```csharp
using QuantConnect;
using QuantConnect.Algorithm;
using QuantConnect.Data.Market;

namespace QuantConnect.Algorithm.CSharp
{
    public class MyFirstStrategy : QCAlgorithm
    {
        private Symbol _spy;
        
        public override void Initialize()
        {
            // 设置回测参数
            SetStartDate(2020, 1, 1);
            SetEndDate(2023, 12, 31);
            SetCash(100000);
            
            // 添加股票
            _spy = AddEquity("SPY", Resolution.Daily).Symbol;
        }
        
        public override void OnData(Slice data)
        {
            // 简单策略：如果没有持仓就买入
            if (!Portfolio.Invested)
            {
                SetHoldings(_spy, 1.0);
                Debug("买入 SPY");
            }
        }
    }
}
```

### 4. 运行你的策略

修改 config.json：
```json
{
  "algorithm-type-name": "MyFirstStrategy"
}
```

按 F5 运行，或：
```powershell
cd Launcher/bin/Debug
dotnet QuantConnect.Lean.Launcher.dll
```

## 📊 查看结果

运行完成后，在 `Launcher/bin/Debug/` 目录查看：

- `MyFirstStrategy-log.txt` - 日志文件
- 终端输出的统计信息

关键指标：
- **Net Profit** - 净收益百分比
- **Sharpe Ratio** - 夏普比率（风险调整后收益）
- **Max Drawdown** - 最大回撤
- **Win Rate** - 胜率

## 🎯 常见策略模式

### 双均线策略

```csharp
private ExponentialMovingAverage _fastEma;
private ExponentialMovingAverage _slowEma;

public override void Initialize()
{
    SetStartDate(2020, 1, 1);
    SetCash(100000);
    
    var spy = AddEquity("SPY", Resolution.Hour).Symbol;
    
    _fastEma = EMA(spy, 12);
    _slowEma = EMA(spy, 26);
}

public override void OnData(Slice data)
{
    if (!_fastEma.IsReady || !_slowEma.IsReady) return;
    
    // 金叉买入
    if (_fastEma > _slowEma && !Portfolio.Invested)
    {
        SetHoldings("SPY", 1.0);
    }
    // 死叉卖出
    else if (_fastEma < _slowEma && Portfolio.Invested)
    {
        Liquidate("SPY");
    }
}
```

### 突破策略

```csharp
private RollingWindow<decimal> _highs;

public override void Initialize()
{
    SetStartDate(2020, 1, 1);
    SetCash(100000);
    
    AddEquity("SPY", Resolution.Daily);
    _highs = new RollingWindow<decimal>(20);
}

public override void OnData(Slice data)
{
    if (!data.Bars.ContainsKey("SPY")) return;
    
    var bar = data.Bars["SPY"];
    _highs.Add(bar.High);
    
    if (!_highs.IsReady) return;
    
    // 突破20日高点买入
    if (bar.Close > _highs.Max() && !Portfolio.Invested)
    {
        SetHoldings("SPY", 1.0);
    }
}
```

## ❓ 常见问题

### Q: 数据文件在哪里？
A: 需要下载到 `Data/` 目录，使用 `lean data download` 命令

### Q: 如何调试算法？
A: Visual Studio/VS Code 中按 F5，在代码中设置断点

### Q: 支持 Python 吗？
A: 支持，在 `Algorithm.Python` 目录创建 `.py` 文件即可

### Q: 如何连接实盘？
A: 修改 config.json 的 `environment` 为 `live-*`，配置券商信息
