## 2. 项目架构详解

### 2.1 核心项目依赖关系

```
Launcher (入口)
    ↓
Engine (核心引擎)
    ↓
├── Algorithm (算法基类)
├── Common (数据结构和工具)
├── Indicators (技术指标)
├── Brokerages (券商接口)
├── Configuration (配置管理)
└── AlgorithmFactory (算法加载)
```

### 2.2 关键项目说明

#### 2.2.1 引擎核心

| 项目 | 命名空间 | 作用 | 关键类 |
|------|---------|------|--------|
| **Engine** | `QuantConnect.Lean.Engine` | 交易引擎核心 | `Engine`, `AlgorithmManager`, `Results` |
| **Launcher** | `QuantConnect.Lean.Launcher` | 启动器 | `Program` |
| **Common** | `QuantConnect` | 基础库 | `Symbol`, `Security`, `Order` |

#### 2.2.2 算法开发

| 项目 | 命名空间 | 作用 | 扩展点 |
|------|---------|------|--------|
| **Algorithm** | `QuantConnect.Algorithm` | 算法基类 | 继承 `QCAlgorithm` |
| **Algorithm.Framework** | `QuantConnect.Algorithm.Framework` | 框架模块 | Alpha, Portfolio, Execution, Risk |
| **Algorithm.CSharp** | `QuantConnect.Algorithm.CSharp` | C# 算法示例 | 参考示例 |
| **Algorithm.Python** | `QuantConnect.Algorithm.Python` | Python 算法支持 | Python 互操作 |

#### 2.2.3 数据与指标

| 项目 | 命名空间 | 作用 |
|------|---------|------|
| **Indicators** | `QuantConnect.Indicators` | 技术指标库（SMA、MACD、RSI等） |
| **Data** | - | 市场数据存储目录 |
| **DownloaderDataProvider** | `QuantConnect.DownloaderDataProvider` | 数据下载工具 |

#### 2.2.4 交易执行

| 项目 | 命名空间 | 作用 |
|------|---------|------|
| **Brokerages** | `QuantConnect.Brokerages` | 券商接口实现（IB、TD、Alpaca等） |

#### 2.2.5 辅助工具

| 项目 | 命名空间 | 作用 |
|------|---------|------|
| **ToolBox** | `QuantConnect.ToolBox` | 数据转换、下载工具集 |

## 4. 开发工作流

### 4.1 创建新算法

#### 方式一：在 Algorithm.CSharp 项目中添加

```csharp
// Algorithm.CSharp/MyCustomStrategy.cs
using QuantConnect;
using QuantConnect.Algorithm;
using QuantConnect.Data.Market;
using QuantConnect.Indicators;

namespace QuantConnect.Algorithm.CSharp
{
    public class MyCustomStrategy : QCAlgorithm
    {
        private ExponentialMovingAverage _fastEma;
        private ExponentialMovingAverage _slowEma;
        private Symbol _symbol;

        public override void Initialize()
        {
            // 设置回测时间和资金
            SetStartDate(2020, 1, 1);
            SetEndDate(2023, 12, 31);
            SetCash(100000);

            // 添加股票
            _symbol = AddEquity("SPY", Resolution.Hour).Symbol;

            // 创建指标
            _fastEma = EMA(_symbol, 12, Resolution.Hour);
            _slowEma = EMA(_symbol, 26, Resolution.Hour);

            // 预热指标
            SetWarmUp(TimeSpan.FromDays(30));
        }

        public override void OnData(Slice slice)
        {
            // 等待指标预热完成
            if (IsWarmingUp) return;

            // 检查数据可用性
            if (!_fastEma.IsReady || !_slowEma.IsReady) return;

            // 交易逻辑：金叉买入，死叉卖出
            if (_fastEma > _slowEma)
            {
                if (!Portfolio.Invested)
                {
                    SetHoldings(_symbol, 1.0);
                    Debug($"{Time}: 金叉买入，快线={_fastEma}, 慢线={_slowEma}");
                }
            }
            else if (_fastEma < _slowEma)
            {
                if (Portfolio.Invested)
                {
                    Liquidate(_symbol);
                    Debug($"{Time}: 死叉卖出，快线={_fastEma}, 慢线={_slowEma}");
                }
            }
        }

        public override void OnOrderEvent(OrderEvent orderEvent)
        {
            // 订单状态变化时触发
            if (orderEvent.Status == OrderStatus.Filled)
            {
                Debug($"订单成交: {orderEvent}");
            }
        }
    }
}
```

### 5.5 常见问题排查

#### 问题1：数据缺失
```
20260215 08:00:00 TRACE:: Data for SPY not found
```
**解决方案**：
- 检查 `Data/` 目录是否有对应的数据文件
- 使用 Lean CLI 或 ToolBox 下载数据
- 确认配置文件中 `data-folder` 路径正确

#### 问题2：订单被拒绝
```
OrderID: 1 Status: Invalid - Insufficient buying power
```
**解决方案**：
```csharp
// 检查错误信息
public override void OnOrderEvent(OrderEvent orderEvent)
{
    if (orderEvent.Status == OrderStatus.Invalid)
    {
        Debug($"订单无效: {orderEvent.Message}");
    }
}

// 使用安全的下单方式
if (Portfolio.MarginRemaining > 0)
{
    var quantity = CalculateOrderQuantity(_symbol, 0.5); // 使用50%资金
    MarketOrder(_symbol, quantity);
}
```

#### 问题3：指标未就绪
```
System.InvalidOperationException: Indicator not ready
```
**解决方案**：
```csharp
public override void OnData(Slice slice)
{
    // 始终检查指标是否就绪
    if (!_indicator.IsReady)
    {
        return;
    }
    
    // 使用指标
    var value = _indicator.Current.Value;
}
```

```csharp
// 创建自定义数据类
public class CustomData : BaseData
{
    public decimal MyValue { get; set; }
    
    public override SubscriptionDataSource GetSource(SubscriptionDataConfig config, DateTime date, bool isLiveMode)
    {
        // 返回数据源URL或文件路径
        var source = $"https://myapi.com/data/{config.Symbol}_{date:yyyyMMdd}.csv";
        return new SubscriptionDataSource(source, SubscriptionTransportMedium.RemoteFile);
    }
    
    public override BaseData Reader(SubscriptionDataConfig config, string line, DateTime date, bool isLiveMode)
    {
        // 解析数据
        var csv = line.Split(',');
        return new CustomData
        {
            Symbol = config.Symbol,
            Time = DateTime.Parse(csv[0]),
            MyValue = decimal.Parse(csv[1])
        };
    }
}

// 在算法中使用
public override void Initialize()
{
    AddData<CustomData>("MYSYMBOL", Resolution.Daily);
}
```

### 6.2 创建自定义指标

```csharp
// Indicators/MyCustomIndicator.cs
public class MyCustomIndicator : IndicatorBase<IndicatorDataPoint>
{
    private readonly int _period;
    private readonly RollingWindow<decimal> _window;
    
    public MyCustomIndicator(int period) : base($"MYCUSTOM({period})")
    {
        _period = period;
        _window = new RollingWindow<decimal>(period);
    }
    
    public override bool IsReady => _window.IsReady;
    
    protected override decimal ComputeNextValue(IndicatorDataPoint input)
    {
        _window.Add(input.Value);
        
        if (!IsReady) return 0m;
        
        // 你的指标计算逻辑
        return _window.Average();
    }
}

// 在算法中使用
public override void Initialize()
{
    var myIndicator = new MyCustomIndicator(20);
    RegisterIndicator(_symbol, myIndicator, Resolution.Daily);
}
```

```typescript
import React, { useEffect, useState } from 'react';

  backtestId: string;

const BacktestMonitor: React.FC<BacktestMonitorProps> = ({ backtestId }) => {
  const [connection, setConnection] = useState<any>(null);
  const [progress, setProgress] = useState(0);
  const [logs, setLogs] = useState<string[]>([]);
  const [stats, setStats] = useState<any>({});

  useEffect(() => {
    // 建立 SignalR 连接
    const newConnection = new HubConnectionBuilder()
      .withUrl('http://localhost:5000/hubs/backtest')
      .withAutomaticReconnect()
      .build();

    setConnection(newConnection);
  }, []);

  useEffect(() => {
    if (connection) {
      connection.start()
        .then(() => {
          console.log('Connected to SignalR');
          
          // 订阅回测
          connection.invoke('SubscribeToBacktest', backtestId);
          
          // 监听进度更新
          connection.on('ProgressUpdate', (data: any) => {
            setProgress(data.percentage);
            setStats(data.statistics);
          });
          
          // 监听日志消息
          connection.on('LogMessage', (message: string) => {
            setLogs(prev => [...prev, message]);
          });
        })
        .catch((error: any) => console.log('Connection failed: ', error));
    }
    
    return () => {
      if (connection) {
        connection.stop();
      }
    };
  }, [connection, backtestId]);

      </Card>
```

### 7.5 数据库设计

```sql
-- 创建数据库表
CREATE TABLE Strategies (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    Name TEXT NOT NULL UNIQUE,
    Description TEXT,
    Language TEXT NOT NULL,
    Code TEXT NOT NULL,
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE Backtests (
    Id TEXT PRIMARY KEY,
    StrategyId INTEGER NOT NULL,
    StartDate DATE NOT NULL,
    EndDate DATE NOT NULL,
    InitialCash DECIMAL(18,2) NOT NULL,
    Status TEXT NOT NULL, -- Running, Completed, Failed, Stopped
    Progress DECIMAL(5,2) DEFAULT 0,
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    CompletedAt DATETIME,
    FOREIGN KEY (StrategyId) REFERENCES Strategies(Id)
);

CREATE TABLE BacktestResults (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    BacktestId TEXT NOT NULL,
    TotalReturn DECIMAL(10,4),
    SharpeRatio DECIMAL(10,4),
    MaxDrawdown DECIMAL(10,4),
    WinRate DECIMAL(5,2),
    TotalOrders INTEGER,
    ResultJson TEXT, -- 完整的 JSON 结果
    FOREIGN KEY (BacktestId) REFERENCES Backtests(Id)
);

CREATE TABLE BacktestLogs (
    Id INTEGER PRIMARY KEY AUTOINCREMENT,
    BacktestId TEXT NOT NULL,
    Timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
    Level TEXT NOT NULL, -- Debug, Info, Warning, Error
    Message TEXT NOT NULL,
    FOREIGN KEY (BacktestId) REFERENCES Backtests(Id)
);
```

2. **使用合适的数据分辨率**：日线数据比分钟数据快得多

4. **优化算法逻辑**：避免在 `OnData` 中执行耗时操作

### 9.4 安全建议

2. **限制日志输出**：避免记录敏感信息
3. **使用 HTTPS**：生产环境必须使用 SSL/TLS
4. **定期更新依赖**：及时更新 NuGet 包修复漏洞
