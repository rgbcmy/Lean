## 🛠️ 配置速查

### 修改运行的策略
编辑 `Launcher/bin/Debug/config.json`：
```json
{
  "algorithm-type-name": "YourStrategyName"
}
```

### 切换环境
```json
{
  "environment": "backtesting"  // backtesting | live-paper | live-interactive
}
```

### 数据目录
```json
{
  "data-folder": "../../../Data/"
}
```

## 🐛 常见问题

### Q1: 数据文件缺失
**错误**：`Data for SPY not found`

**解决**：
```bash
# 使用 Lean CLI 下载数据
lean data download --start 20200101 --end 20231231
```

### Q2: 无法连接券商
**错误**：`Connection failed to broker`

**解决**：检查 config.json 中的券商配置，确保账号密码正确

### Q3: 内存不足
**错误**：`OutOfMemoryException`

**解决**：
- 减少数据分辨率（使用日线而非分钟线）
- 限制订阅的品种数量
- 增加系统内存

### Q4: Python 环境问题
**错误**：`Python.NET initialization failed`

**解决**：
```bash
# 安装 Python 3.11
# 设置环境变量
PYTHONNET_PYDLL=C:\Python311\python311.dll
```
