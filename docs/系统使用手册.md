## 第一章：系统概览

### 1.1 Lean 是什么？

Lean 是一个开源的算法交易引擎，支持：
- ✅ **回测（Backtesting）**：用历史数据测试策略
- ✅ **模拟交易（Paper Trading）**：实时数据模拟交易
- ✅ **实盘交易（Live Trading）**：对接真实券商交易
- ✅ **参数优化（Optimization）**：自动寻找最佳参数
- ✅ **研究分析（Research）**：Jupyter 环境数据分析

### 1.2 系统架构


### 2.2 支持的数据类型

#### 2.2.1 股票数据 (Equity)

**可用分辨率**: Tick, Second, Minute, Hour, Daily

**数据字段**:
- **Trade Bar**: Open, High, Low, Close, Volume
- **Quote Bar**: Bid Open/High/Low/Close, Ask Open/High/Low/Close
- **Tick**: Price, Quantity, Exchange, Time

**文件命名规则**:
```
{date}_trade.zip     # 成交数据
{date}_quote.zip     # 报价数据
{date}_trade_quote.zip  # 完整数据
```

**示例代码**:
```csharp
// 添加分钟级美股数据
var spy = AddEquity("SPY", Resolution.Minute);

// 添加日线数据
var aapl = AddEquity("AAPL", Resolution.Daily);

// 添加印度股票
var reliance = AddEquity("RELIANCE", Resolution.Daily, Market.India);
```

#### 2.2.2 期权数据 (Option)

**可用分辨率**: Minute, Hour, Daily

**数据字段**:
- **Greek Parameters**: Delta, Gamma, Vega, Theta, Rho
- **OHLCV**: Open, High, Low, Close, Volume
- **Open Interest**: 持仓量

**期权链筛选**:
```csharp
// 添加期权
var option = AddOption("SPY");

// 筛选期权链
option.SetFilter(universe => universe
    .Strikes(-5, +5)           // 行权价范围：上下5档
    .Expiration(0, 30)         // 到期日范围：30天内
    .IncludeWeeklys());        // 包含周期权
```

#### 2.2.3 期货数据 (Future)

**可用分辨率**: Tick, Second, Minute, Hour, Daily

**主要品种**:
- **股指期货**: ES (E-mini S&P 500), NQ (E-mini Nasdaq)
- **商品期货**: GC (黄金), CL (原油), NG (天然气)
- **农产品**: ZC (玉米), ZW (小麦), ZS (大豆)

**代码示例**:
```csharp
// 添加标准期货合约
var es = AddFuture(Futures.Indices.SP500EMini);
es.SetFilter(0, 90);  // 筛选90天内到期的合约

// 添加连续期货（自动换月）
var continuous = AddFuture(Futures.Indices.SP500EMini,
    dataNormalizationMode: DataNormalizationMode.BackwardsRatio,
    dataMappingMode: DataMappingMode.LastTradingDay,
    contractDepthOffset: 0);  // 0=主力合约, 1=次主力
```

#### 2.2.4 外汇数据 (Forex)

**可用分辨率**: Tick, Second, Minute, Hour, Daily

**主要货币对**:
- **主要**: EURUSD, GBPUSD, USDJPY, USDCHF
- **交叉**:  EURGBP, EURJPY, GBPJPY
- **商品**: AUDUSD, NZDUSD, USDCAD

**代码示例**:
```csharp
// 添加外汇对
var eurusd = AddForex("EURUSD", Resolution.Minute);

// 指定数据源
var gbpusd = AddForex("GBPUSD", Resolution.Hour, Market.FXCM);
```

#### 2.2.5 加密货币数据 (Crypto)

**可用分辨率**: Second, Minute, Hour, Daily

**主要交易所**:
- **Coinbase**: BTCUSD, ETHUSD, LTCUSD
- **Binance**: BTCUSDT, ETHUSDT, BNBUSDT
- **GDAX**: BTC, ETH, LTC

**代码示例**:
```csharp
// 添加加密货币现货
var btc = AddCrypto("BTCUSD", Resolution.Minute, Market.Coinbase);
```

### 3.1 算法分类

#### 3.1.1 模板类算法（Template）

**BasicTemplateAlgorithm** - 最简单的模板
```csharp
public class BasicTemplateAlgorithm : QCAlgorithm
{
    public override void Initialize()
    {
        SetStartDate(2020, 1, 1);
        SetEndDate(2023, 12, 31);
        SetCash(100000);
        AddEquity("SPY", Resolution.Daily);
    }
    
    public override void OnData(Slice data)
    {
        if (!Portfolio.Invested)
        {
            SetHoldings("SPY", 1);
        }
    }
}
```

**BasicTemplateFrameworkAlgorithm** - 框架模式模板
```csharp
public class BasicTemplateFrameworkAlgorithm : QCAlgorithm
{
    public override void Initialize()
    {
        SetStartDate(2020, 1, 1);
        SetCash(100000);
        
        // 使用框架模块
        SetUniverseSelection(new ManualUniverseSelectionModel("SPY"));
        SetAlpha(new ConstantAlphaModel(InsightType.Price, InsightDirection.Up, TimeSpan.FromDays(1)));
        SetPortfolioConstruction(new EqualWeightingPortfolioConstructionModel());
        SetExecution(new ImmediateExecutionModel());
        SetRiskManagement(new MaximumDrawdownPercentPerSecurity(0.02m));
    }
}
```

### 3.4 创建自定义算法

#### 3.4.1 基本结构

```csharp
using QuantConnect;
using QuantConnect.Algorithm;
using QuantConnect.Data;
using QuantConnect.Indicators;

namespace QuantConnect.Algorithm.CSharp
{
    public class MyCustomStrategy : QCAlgorithm
    {
        // 1. 声明成员变量
        private Symbol _symbol;
        private ExponentialMovingAverage _fastEma;
        private ExponentialMovingAverage _slowEma;
        
        // 2. 初始化方法（必须）
        public override void Initialize()
        {
            // 设置回测参数
            SetStartDate(2020, 1, 1);
            SetEndDate(2023, 12, 31);
            SetCash(100000);
            
            // 添加资产
            _symbol = AddEquity("SPY", Resolution.Hour).Symbol;
            
            // 创建指标
            _fastEma = EMA(_symbol, 12);
            _slowEma = EMA(_symbol, 26);
            
            // 预热指标
            SetWarmUp(TimeSpan.FromDays(30));
        }
        
        // 3. 数据事件方法（必须）
        public override void OnData(Slice data)
        {
            // 等待预热
            if (IsWarmingUp) return;
            
            // 等待指标就绪
            if (!_fastEma.IsReady || !_slowEma.IsReady) return;
            
            // 交易逻辑
            if (_fastEma > _slowEma)
            {
                if (!Portfolio.Invested)
                {
                    SetHoldings(_symbol, 1.0);
                    Debug($"买入: FastEMA={_fastEma}, SlowEMA={_slowEma}");
                }
            }
            else if (_fastEma < _slowEma)
            {
                if (Portfolio.Invested)
                {
                    Liquidate(_symbol);
                    Debug($"卖出: FastEMA={_fastEma}, SlowEMA={_slowEma}");
                }
            }
        }
        
        // 4. 订单事件方法（可选）
        public override void OnOrderEvent(OrderEvent orderEvent)
        {
            if (orderEvent.Status == OrderStatus.Filled)
            {
                Debug($"订单成交: {orderEvent}");
            }
        }
        
        // 5. 算法结束方法（可选）
        public override void OnEndOfAlgorithm()
        {
            Log($"最终资产: {Portfolio.TotalPortfolioValue}");
        }
    }
}
```

### 6.1 案例一：双均线策略

**策略说明**:
- 使用 12 日和 26 日 EMA
- 快线上穿慢线：买入
- 快线下穿慢线：卖出

**完整代码**:
```csharp
public class DualEmaStrategy : QCAlgorithm
{
    private Symbol _symbol;
    private ExponentialMovingAverage _fastEma;
    private ExponentialMovingAverage _slowEma;
    private bool _lastCrossAbove;
    
    public override void Initialize()
    {
        SetStartDate(2020, 1, 1);
        SetEndDate(2023, 12, 31);
        SetCash(100000);
        
        _symbol = AddEquity("SPY", Resolution.Daily).Symbol;
        
        _fastEma = EMA(_symbol, 12, Resolution.Daily);
        _slowEma = EMA(_symbol, 26, Resolution.Daily);
        
        SetWarmUp(26, Resolution.Daily);
        
        SetBenchmark("SPY");
    }
    
    public override void OnData(Slice data)
    {
        if (IsWarmingUp) return;
        
        if (!_fastEma.IsReady || !_slowEma.IsReady) return;
        
        var crossAbove = _fastEma > _slowEma;
        
        // 金叉买入
        if (crossAbove && !_lastCrossAbove && !Portfolio.Invested)
        {
            SetHoldings(_symbol, 1.0);
            Debug($"{Time}: 金叉买入 @ {data[_symbol].Price}");
            Plot("Strategy", "Buy", data[_symbol].Price);
        }
        // 死叉卖出
        else if (!crossAbove && _lastCrossAbove && Portfolio.Invested)
        {
            Liquidate(_symbol);
            Debug($"{Time}: 死叉卖出 @ {data[_symbol].Price}");
            Plot("Strategy", "Sell", data[_symbol].Price);
        }
        
        _lastCrossAbove = crossAbove;
        
        // 绘制指标
        Plot("Indicators", "Fast EMA", _fastEma);
        Plot("Indicators", "Slow EMA", _slowEma);
        Plot("Indicators", "Price", data[_symbol].Price);
    }
    
    public override void OnEndOfAlgorithm()
    {
        Log($"最终资产: ${Portfolio.TotalPortfolioValue:N2}");
        Log($"净收益: ${Portfolio.TotalProfit:N2}");
    }
}
```

### 6.3 案例三：期权备兑策略

**策略说明**:
- 持有股票
- 卖出虚值看涨期权收取期权费

**完整代码**:
```csharp
public class CoveredCallStrategy : QCAlgorithm
{
    private Symbol _stock;
    private Symbol _option;
    
    public override void Initialize()
    {
        SetStartDate(2020, 1, 1);
        SetEndDate(2023, 12, 31);
        SetCash(100000);
        
        _stock = AddEquity("SPY", Resolution.Daily).Symbol;
        var option = AddOption("SPY", Resolution.Daily);
        option.SetFilter(universe => universe
            .Strikes(-5, +5)
            .Expiration(20, 45)
            .CallsOnly()
            .OnlyApplyFilterAtMarketOpen());
        
        _option = option.Symbol;
    }
    
    public override void OnData(Slice data)
    {
        // 确保持有股票  
        if (!Portfolio[_stock].Invested)
        {
            SetHoldings(_stock, 1.0);
            return;
        }
        
        // 如果没有期权仓位，寻找合适的期权卖出
        if (!Portfolio.Any(x => x.Value.Invested && x.Key.SecurityType == SecurityType.Option))
        {
            if (data.OptionChains.TryGetValue(_option, out var chain))
            {
                // 选择最近到期、稍微虚值的看涨期权
                var contract = chain
                    .Where(x => x.Right == OptionRight.Call)
                    .Where(x => x.Strike > data[_stock].Price * 1.02m)  // 虚值2%
                    .OrderBy(x => x.Expiry)
                    .ThenBy(x => x.Strike)
                    .FirstOrDefault();
                
                if (contract != null)
                {
                    // 卖出看涨期权
                    var qty = -Portfolio[_stock].Quantity / 100;  // 1手期权对应100股
                    MarketOrder(contract.Symbol, qty);
                    Debug($"{Time}: 卖出看涨期权 {contract.Symbol.Value} @ {contract.LastPrice}");
                }
            }
        }
    }
    
    public override void OnOrderEvent(OrderEvent orderEvent)
    {
        if (orderEvent.Status == OrderStatus.Filled)
        {
            Debug($"订单成交: {orderEvent}");
        }
    }
}
```

### 6.4 案例四：多品种轮动策略

**策略说明**:
- 持有动量最强的3只股票
- 每月重新平衡

**完整代码**:
```csharp
public class MomentumRotationStrategy : QCAlgorithm
{
    private List<Symbol> _symbols;
    private Dictionary<Symbol, RateOfChange> _momentum;
    private const int _topN = 3;
    
    public override void Initialize()
    {
        SetStartDate(2020, 1, 1);
        SetEndDate(2023, 12, 31);
        SetCash(100000);
        
        // 添加股票池
        var tickers = new[] { "SPY", "QQQ", "IWM", "DIA", "EEM", "EFA", "AGG", "TLT", "GLD", "USO" };
        _symbols = new List<Symbol>();
        _momentum = new Dictionary<Symbol, RateOfChange>();
        
        foreach (var ticker in tickers)
        {
            var symbol = AddEquity(ticker, Resolution.Daily).Symbol;
            _symbols.Add(symbol);
            _momentum[symbol] = ROC(symbol, 63);  // 3个月动量
        }
        
        SetWarmUp(63, Resolution.Daily);
        
        // 每月第一个交易日重新平衡
        Schedule.On(
            DateRules.MonthStart("SPY"),
            TimeRules.AfterMarketOpen("SPY", 30),
            Rebalance
        );
    }
    
    private void Rebalance()
    {
        if (IsWarmingUp) return;
        
        // 计算每个股票的动量得分
        var momentumScores = _symbols
            .Where(s => _momentum[s].IsReady)
            .Select(s => new { Symbol = s, Score = _momentum[s].Current.Value })
            .OrderByDescending(x => x.Score)
            .Take(_topN)
            .ToList();
        
        Debug($"{Time}: 本月前{_topN}名:");
        foreach (var item in momentumScores)
        {
            Debug($"  {item.Symbol.Value}: {item.Score:P2}");
        }
        
        // 清仓不在榜单的股票
        foreach (var symbol in _symbols)
        {
            if (!momentumScores.Any(x => x.Symbol == symbol) && Portfolio[symbol].Invested)
            {
                Liquidate(symbol);
            }
        }
        
        // 平分资金买入前N名
        var weight = 1.0m / _topN;
        foreach (var item in momentumScores)
        {
            SetHoldings(item.Symbol, weight);
        }
    }
    
    public override void OnData(Slice data)
    {
        // 交易逻辑在定期任务中处理
    }
}
```

```
Indicator EMA(12) is not ready
```

```csharp
public override void OnData(Slice data)
{
    // 始终检查指标是否就绪
    if (!_ema.IsReady)
    {
        return;

    // 或者使用 WarmUp
    SetWarmUp(TimeSpan.FromDays(30));
    
    if (IsWarmingUp) return;
}
```

```csharp
// 避免在 OnData 中执行耗时操作

    var sma = History("SPY", 20).Select(x => x.Close).Average();

    if (_sma.IsReady)
    {
        var smaValue = _sma.Current.Value;
    }
}

// 使用定时任务而不是 OnData
Schedule.On(

);
```
