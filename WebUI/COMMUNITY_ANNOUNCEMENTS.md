## Reddit - r/algotrading

**Title**: [New Release] Lean WebUI v1.0.0 - Modern Web Interface for QuantConnect Lean 🚀

**Post**:

Hi r/algotrading!

I'm excited to announce the **first official release of Lean WebUI v1.0.0** - a modern, full-featured web interface for the QuantConnect Lean algorithmic trading engine!

## 🌟 What is Lean WebUI?

Lean WebUI brings a powerful browser-based interface to Lean, making algorithmic trading more accessible. Instead of configuring everything through code and config files, you now get a complete web application with:

- 🏦 **IBKR Integration**: Connect to Interactive Brokers for paper and live trading
- 📈 **Real-Time Trading**: Trade US stocks and ETFs with market and limit orders
- 🤖 **Strategy Management**: Create, configure, and monitor Lean strategies through the UI
- 📊 **Advanced Charting**: K-line charts, technical indicators, live market data
- ⚡ **Real-Time Updates**: WebSocket-powered live order, position, and market data
- 🔒 **Enterprise Security**: JWT auth, encrypted credentials, audit logging
- 🐳 **Docker Ready**: Production-ready Docker deployment

## 📦 Tech Stack

- **Backend**: ASP.NET Core 10, Entity Framework, SignalR
- **Frontend**: React 19, TypeScript, Ant Design
- **Database**: PostgreSQL or SQLite
- **Infrastructure**: Docker, Docker Compose

## 🚀 Quick Start

```bash
git clone https://github.com/QuantConnect/Lean.git
cd Lean/WebUI
docker-compose up -d
# Access at http://localhost:5000
```

Default credentials: `admin` / `Admin@123` (change immediately!)
